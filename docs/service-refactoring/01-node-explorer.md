## 当前职责与依据

生产入口为 PHP/webman，承载登录会话、节点列表/筛选、链接获取、服务监控和前端静态文件。容器名 node-explorer，监控心跳键为 `api`，两者不是两个服务。

依据：[路由](../../webman/config/route.php)、[LiveResults](../../webman/app/service/LiveResults.php)、[Heartbeat](../../webman/app/service/Heartbeat.php)、[ServiceMonitor](../../webman/app/service/ServiceMonitor.php)、[前端](../../src/App.tsx)。

当前查询从 live facts 取事实，在 PHP 中规范化与分页，再按页补 payload；LiveResults 同时承担查询、筛选排序与响应组装。`/api/health` 是不查库的存活探针；API 数据库心跳随结果请求触发，不能简单用“无请求时心跳过期”推断进程已退出。监控聚合只读，但 API 心跳会写服务状态表。
