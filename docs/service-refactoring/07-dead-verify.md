## 当前职责与依据

独立二进制按批拉候选，启动私有 Mihomo 做受控握手，根据新鲜证据执行受保护删除，随后批量压缩快照。独立心跳不依赖一批完成。它不通过 Redis 领任务，也不使用 shared-mihomo strict 通道；Compose 的公共依赖不等于实际运行依赖。

## 验收与回退

先用固定脱敏候选集 dry-run 对比判定，再在隔离库测试保护否决、并发恢复、tombstone 重投、删除中断与压缩重跑。执行后端检查及真实私有 Mihomo 验证，不能仅测试 TCP 端口。生产启用前准备暂停删除与数据库恢复步骤；镜像回退只能回退程序，不能撤销已经提交的永久删除。
