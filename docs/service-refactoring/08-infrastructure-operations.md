# 基础设施与运维

应用保留五个独立入口；PostgreSQL 为外部依赖。可选 subs-check 只提供上游订阅文件，Qilan / 公开源在采集进程内运行。Xray / Mihomo 是测活和出口进程启动的私有子进程，无共享 manager 或 Redis。

共享 schema 由部署初始化，各服务只维护自有调度表。连接池预算需要计入服务锁连接和 PHP worker。备份脚本位于 `deploy/pg-backup.sh`，容量统计位于 `deploy/pg-stats.sh`。

线上 2026-10-26 已停止本项目全部容器并禁用自动更新、开机启动与容器自动重启，详情见 [清理记录](11-project-cleanup.md)。新镜像部署后才能恢复定时更新；旧镜像不兼容清理后的数据库。回退需要恢复数据库及完整旧配置，不能混用新旧写入者。

后续运维：验证新版本启动、健康检查、来源输出新鲜度与总连接池预算；按实际增长设置备份保留周期。当前没有历史监控采样服务；API 仅返回当前心跳，历史桶与占位指标已删除。

部署脚本验证：`python3 -m unittest discover -s deploy -p 'test_*.py'`。备份应实际恢复到隔离库，校验保留事实摘要；仅文件存在不算恢复验证。
