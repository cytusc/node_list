2. **🟡 Qilan session 手工刷新**：`secrets/qilan-session.txt` 今天 08:47 手工更新过一次；无任何自动刷新任务（root crontab / cron.d / systemd timer 均无）。失效后采集中断，有飞书告警兜底（v1.3.38 已验证链路通）。
3. **🟡 数据库无自动备份**：node_explorer 库 ~65MB，`backups/` 目录只有部署脚本和 .env 备份，没有 pg_dump 定期任务。
